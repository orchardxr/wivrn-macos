## WiVRn for macOS 26.9.4

26.9.3 was never released (its build failed), so this release carries its changes.

- **OpenComposite works like on Linux**: while a headset is connected, WiVRn points OpenVR games at OpenComposite
  (installed in `~/Library/Application Support/OpenComposite/runtime`) and puts the previous OpenVR setting back when
  the session ends. Settings › OpenVR compatibility library shows the OpenComposite it found, or lets you pick
  another one or turn it off.
- **Encoder list for the Mac**: Settings › Encoder offers Auto, VideoToolbox and x264.
- **macOS hints in the setup wizard and Troubleshoot**: USB cable and USB debugging instead of udev rules, the macOS
  firewall instead of ports, game audio captured without choosing an output device, VarboR and OpenComposite instead
  of SteamVR. "Report an issue" and About link to this project.
- **Self-update** refreshes the app icon in Finder and Launchpad.
- **WiVRn.app only loads its own libraries**: every Homebrew library it needs is bundled, and on a Mac with
  Homebrew installed it no longer picks up Homebrew's copies.

### Which file to download

- **`WiVRn-26.9.4.zip`**: the app (dashboard, server and OpenXR runtime). Unzip it and drag WiVRn.app to
  Applications. This is the one you want; WiVRn.app also updates itself from it.
- **`wivrn-macos-26.9.4-headless.zip`**: server and OpenXR runtime only, no dashboard (`bin/wivrn-server`), for running
  the server from a terminal or scripts. Was `wivrn-macos-<version>.zip` before this release.
