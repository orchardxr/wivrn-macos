## WiVRn for macOS 26.9.5

- **WiVRn is a Dock app**: the menu-bar icon is gone. Click WiVRn in the Dock to show its window; closing the window
  keeps WiVRn (and the server) running in the Dock. Quit it from the Dock or with ⌘Q; while a headset session runs it
  asks first.

### Which file to download

- **`WiVRn-26.9.5.zip`**: the app (dashboard, server and OpenXR runtime). Unzip it and drag WiVRn.app to
  Applications. This is the one you want; WiVRn.app also updates itself from it.
- **`wivrn-macos-26.9.5-headless.zip`**: server and OpenXR runtime only, no dashboard (`bin/wivrn-server`), for running
  the server from a terminal or scripts.
