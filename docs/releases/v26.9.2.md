## WiVRn for macOS 26.9.2

- **Menu-bar app**: WiVRn lives in the menu bar (no Dock icon), so its menu opens over a game or any app in full
  screen. The menu shows the server status, Show WiVRn and Quit WiVRn.
- **Window on the desktop**: Show WiVRn switches to the desktop with the dashboard focused; closing the window keeps
  WiVRn running in the menu bar.
- **Self-update relaunch fixed**: after an update the new version starts its own D-Bus, so the server comes up
  without a restart.
- **App icon**, and **adb** is found when WiVRn starts from Finder (Homebrew `android-platform-tools`).
- **No Linux leftovers** in the Steam box and the server log; the server no longer reads a config file from its build
  folder.
